PynaMIT
-------

PynaMIT simulates inductive magnetosphere-ionosphere-thermosphere coupling on
a spherical ionospheric shell. Start with the interactive workflow, then use
the operator conventions and API reference when developing a new physical
input, response term, or analysis.
